## What I Learned

I learned about:

- Git repositories
- Local repositories
- GitHub repositories
- Initializing repositories
- Cloning repositories
- Working with tracked files
- Untracked files
- Repository status
- Working directory
- Staging area

## What I Practiced

I practiced creating Git repositories for projects and working with existing repositories.

I used Git commands to initialize repositories, check their status, track files, and understand the relationship between the project files and the Git repository.

I also practiced cloning a repository and working with the files inside the cloned project.

## What I Understand

I now understand that a Git repository contains the information Git uses to track changes in a project.

I understand the difference between creating a repository locally with `git init` and obtaining an existing repository using `git clone`.

I also understand that Git can be used with existing projects without changing the way the project itself is organized.
