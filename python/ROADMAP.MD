# Python Roadmap

This roadmap defines the Python learning path for the Engineering Learning Journal.

The **roadmap.sh Python roadmap** is the primary reference for the concepts and tools covered in this roadmap.

The 10 core topics below are the organizational structure used in this repository. Additional subjects from the roadmap.sh path are kept under **Additional Python Topics** so that the core learning sequence remains clear.

The goal is not to complete every item blindly. The goal is to understand the concepts, practice them, build with them, and document evidence of real understanding.
