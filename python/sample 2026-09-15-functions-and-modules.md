# Functions and Modules

Date: 2026-09-15

## What I learned

- Functions allow code to be organized into reusable blocks.
- Parameters allow functions to receive data.
- Return values allow functions to send results back.
- Modules allow related Python code to be separated into files.
- Python functions can be imported from another module.

## What I understand

I understand how to create a function, pass arguments
to it and return a value.

I also understand why separating functions into modules
can make a project easier to maintain.

## What confused me

At first I confused parameters with arguments.

I also wasn't completely sure when I should create a
separate module.

## What I built or practiced

I created a small student grade calculator.

The project uses functions to:

- calculate an average
- determine a grade
- display the result

I also separated some functions into another Python module.

## Errors/problems I encountered

When I tested an empty list, the program produced a
ZeroDivisionError.

## How I solved them

I added input validation before performing the calculation.

## Security/engineering lesson

Even simple programs should handle unexpected input.

I learned that validation is important because software
should not assume that input will always be correct.
