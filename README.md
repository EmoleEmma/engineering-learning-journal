# Engineering Learning Journey

A practical learning journal documenting my progression toward Software Engineering, Application Security, Cloud, and DevSecOps.

This repository records what I learn, what I build, problems I encounter, how I solve them, and the engineering lessons I take from the process.

The goal is not to collect certificates or watch tutorials endlessly.

The goal is to:

- Understand engineering concepts
- Build working systems
- Test what I build
- Learn secure development practices
- Document technical decisions
- Develop problem-solving ability
- Build evidence of consistent technical growth
- Become capable of explaining my work without relying on notes

---

## 🎯 Long-Term Direction

**Software Engineering → Application Security → Cloud Security / DevSecOps**

My learning journey is designed to build strong software engineering fundamentals first, then progressively add backend engineering, application security, cloud and DevSecOps.

# 📅 Weekly Learning Target

The weekly target is a guideline, not a competition.

Aim for:

- 4–5 focused learning entries
- 1 practical exercise, lab, or small feature
- 1 weekly engineering review
- At least 1 meaningful GitHub commit connected to genuine work
- Documentation of important problems and solutions

A week with fewer entries can still be successful if the work was substantial.

University academics remain the first priority.

---

# 📊 Monthly Learning Target

Aim for approximately:

- 16–20 learning entries
- 4 weekly reviews
- 1 meaningful mini-project, feature, lab series, or substantial improvement
- Clear GitHub evidence
- 1 end-of-month reflection

Quality is more important than quantity.

A meaningful implementation with tests is stronger evidence than many empty learning notes.

# 🔄 Weekly Engineering Review

A weekly review is a short 10–20 minute checkpoint at the end of the week.

It answers:

1. What did I learn?
2. What did I build?
3. What problems did I encounter?
4. What did I solve?
5. What evidence did I add to GitHub?
6. What was my biggest lesson?
7. What should I learn next?
