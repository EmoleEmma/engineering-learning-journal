# Git & GitHub Practical Work

This folder contains the practical exercises and experiments I complete while
learning Git and GitHub.

The purpose of these exercises is to turn Git concepts into practical
experience.

Rather than creating artificial software projects, I use repositories,
branches, commits, merge conflicts, remote repositories, documentation, and
GitHub workflows to practice how Git is actually used during software
development.

## Learning Approach

Each practical exercise follows a simple process:

**Learn → Practice → Make a mistake → Investigate → Fix → Document**

The goal is to understand what Git is doing rather than memorizing commands.
